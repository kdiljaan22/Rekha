REKHA BIRTHDAY WEBSITE
=======================

Files:
- index.html
- assets/rekha-1.jpg
- assets/rekha-2.jpg

GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html and the assets folder.
3. Open Settings > Pages.
4. Select Deploy from a branch, choose main and / (root), then Save.
5. Open the Pages URL after deployment.

The website is static and needs no server or database.
